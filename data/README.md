# Data

This directory should contain the 7th Korean Working Environment Survey (WES-7) raw data file.

## How to Obtain the Data

1. Visit the KOSHRI data portal: https://oshri.kosha.or.kr
2. Navigate to the Working Environment Survey (작업환경 실태조사) section
3. Download the 7th wave (2024) dataset
4. Place `Dataset1.csv` at the following path:

```
data/작업환경 실태조사/7차_작업환경 실태조사/[CSV] 제7차 작업환경실태조사 데이터(CSV)/Dataset1.csv
```

## File Details

- **File**: `Dataset1.csv`
- **Format**: CSV, UTF-8 with BOM
- **Rows**: ~20,263 establishments
- **Columns**: 283 variables
- **Year**: 2024

## Notes

- The WES is a nationally representative establishment-level survey administered by the Korea Occupational Safety and Health Research Institute (KOSHRI).
- Only `Dataset1.csv` is required for this analysis (Datasets 2 and 3 contain chemical inventory and material-level data not used here).
- Data use is subject to KOSHRI's terms and conditions.
