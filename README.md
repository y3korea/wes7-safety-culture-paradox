# wes7-safety-culture-paradox

Replication code for:

**The Safety Culture–Injury Paradox Explained by Occupational Confounding: A National Establishment Survey of 20,262 Korean Workplaces**

Heo S, Choi T, Choi W. *Safety Science* (submitted).

## Overview

This repository contains the analysis code for a cross-sectional study of 20,262 Korean establishments from the 7th Korean Working Environment Survey (WES-7, 2024). The study examines the relationship between establishment-level safety culture (15 items across 5 dimensions) and officially approved occupational injuries, with rigorous adjustment for industry, firm size, and prior injury trajectories.

## Key Findings

1. **Unadjusted** analyses show a paradoxical **positive** association between safety culture and injuries (overall IRR = 1.18, 95% CI 1.13–1.23, p < 0.001).
2. **Adjusted** analyses (industry FE + firm size + historical injuries) show a completely null association (IRR = 1.01, 95% CI 0.96–1.06, p = 0.70).
3. The adjusted estimate is **statistically equivalent to the null** within a ±10% margin (two one-sided tests, p < 0.001) — precisely null, not merely underpowered. The apparent paradox is largely explained by confounding by occupational structure rather than a genuine effect of safety culture.
4. Findings are robust across 5 sensitivity analyses, 3 exposure-offset / size-specification checks, 5 firm-size strata, a restricted cubic spline (non-linearity p = 0.35, with 95% CI band), and held-out machine-learning feature importance (random-forest permutation importance, held-out ROC-AUC = 0.83).
5. Measurement: the 5-factor model fits far better than a 1-factor alternative (ΔCFI = 0.142) with adequate convergent validity (CR 0.84–0.95; AVE 0.72–0.87), though the dimensions are strongly intercorrelated (Fornell–Larcker criterion not met for the Training–Systems pair).

## Reproducing the Analysis

### 1. Environment Setup

```bash
pip install -r requirements.txt
```

### 2. Data Preparation

Download WES-7 Dataset1 (2024) from [KOSHRI](https://oshri.kosha.or.kr) and place it in the `data/` directory. See `data/README.md` for the expected file structure.

### 3. Run Notebooks Sequentially

```
0_extract.ipynb     → wes7_raw.csv (N=20,262)
1_preprocess.ipynb  → analytic_sample.csv (N=20,262)
2_analysis.ipynb    → all revised tables/figures (CFA 5-vs-1 factor, NB, equivalence,
                       RCS+CI, offset robustness, permutation importance, DAG, scatter)
```

Running the three notebooks in order reproduces every number in the manuscript. `2_analysis.ipynb` contains exactly the code in `analysis_revision.py`; either entry point gives identical, deterministic results.

Each notebook runs in Google Colab or any Jupyter environment. Path handling is portable: the notebooks auto-detect Colab versus local execution.

### 4. Reproduce the manuscript results in one step

All results, tables, and figures reported in the manuscript are reproduced end-to-end by a single script that reads `output/pre_output/analytic_sample.csv`:

```bash
python analysis_revision.py
```

This writes a timestamped folder under `output/analysis_output/run_revised_<ts>/` containing every table (CSV), every figure (300-dpi PNG: DAG, confounding forest, between-industry scatter, RCS dose–response with 95% CI band, permutation-importance), a graphical abstract, and `results_for_manuscript.json` with all headline numbers. The script is deterministic (`random_state = 42`) and does **not** require the `shap`/`numba` toolchain — feature importance uses scikit-learn's model-agnostic permutation importance on held-out data.

## Methods Summary

| Component | Detail |
|-----------|--------|
| Design | Cross-sectional, establishment-level |
| Sample | N=20,262 Korean establishments (WES-7, 2024) |
| Exposure | 5-factor safety culture (15 items, 5-point Likert) |
| Outcome | Officially approved 2024 occupational injury count (K-WCI verified) |
| Analysis | Negative binomial regression with industry fixed effects |
| Measurement validation | CFA (semopy): 5- vs 1-factor fit, standardized loadings, CR, AVE, Fornell–Larcker |
| Null interpretation | Equivalence testing (TOST, ±10% ROPE); E-value reported for the unadjusted (non-null) estimate |
| Sensitivity | 5 pre-specified analyses + exposure-offset (top=200/300/500) & categorical-size checks + RCS with 95% CI band and non-linearity LR test + size-stratified |
| Feature importance | Random forest, train/test split, held-out ROC-AUC, permutation importance (model-agnostic) |
| Software | Python ≥3.9, statsmodels 0.14, semopy 2.3, scikit-learn ≥1.3, patsy, scipy, matplotlib |

## Auto-Generated Manuscript

The `2_analysis.ipynb` notebook automatically generates the Methods and Results sections of the manuscript in English (Safety Science style) as part of its execution. Output files are saved to `paper/auto/`:

- `00_abstract.md` — 300-word structured abstract
- `01_methods_section_2.1-2.3.md` — Data source, variables, missing data
- `02_methods_section_2.4-2.6.md` — Scale construction, outcomes, STROBE
- `03_methods_section_2.7.md` — Statistical analysis
- `04_results_section_3.1-3.7.md` — Full Results (7 subsections)
- `manuscript_draft_methods_results.md` — Unified draft

All numerical values in the generated text are dynamically inserted from the actual analysis results, ensuring consistency between code output and manuscript.
